# AI択一対策（司法書士・スタンドアロン版）

依存なしの静的Webアプリです（`index.html` + `app.js` + `styles.css`）。

## 起動方法

```bash
cd /workspace/shoshi-ox-app
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8765/index.html を開いてください。
（`index.html` を直接ダブルクリックで開いても動きますが、履歴はオリジンごとに保存されるため、同じURLで開くことをおすすめします。）

## 使い方

- **練習**：問題文を読み、左の「〇」か右の「×」を押します。正誤・解説・条文が表示され、「次の問へ」で進みます。
  キーボード：`o`/`1`/`←` で〇、`x`/`2`/`→` で×、`Enter` で次へ。
- **弱点**：過去に一度でも誤答した肢だけを出題します。
- **結果**：今回のセッションの結果、肢ごとの通算正答率と直近10回の○×、セッション履歴を表示します。

## 履歴の保存（localStorage）

キー `shoshi-ox-v1` に JSON で保存され、再読み込みやブラウザを閉じても残ります。

```json
{
  "version": 2,
  "history": { "001": [ { "at": "2026-10-30T12:34:56.000Z", "correct": true, "picked": "o" } ] },
  "sessions": [ { "id": "s...", "kind": "all|weak|single", "startedAt": "...", "endedAt": "...",
                  "total": 4, "answered": 4, "ok": 3, "ng": 1, "results": { "001": { "at": "...", "correct": true, "picked": "o" } } } ],
  "current": { "...": "進行中のセッション（途中から再開用）" },
  "understanding": { "001": 3 },
  "ui": { "mode": "practice" }
}
```

- 解答するたびに `history[問題ID]` に1件追加されます（`at` はISO時刻、`picked` は `"o"` か `"x"`）。
- 結果パネルの「理解度」は左から 3すぐ解ける（緑）・2ふつう（青灰）・1わからない（赤）です。選んだ数値は `understanding[問題ID]` に上書き保存されます。カードと画面の色は、いま表示している問の理解度だけを使います。練習・弱点・結果を切り替えても、その問の色は残ります。別の問に進んだときだけ、その問の理解度（未設定なら通常の背景）に変わります。以前の5段階で保存した 5 は 3、4 と 3 は 2、2 と 1 は 1 に一度だけ読み替えます。
- セッション終了時（最後の問の後、または「中断して結果へ」）に `sessions` の先頭に記録されます（最大100件）。
- 「結果」画面の「履歴をすべて消去」で初期化できます。

## 更新方法

問題の追加・修正は `app.js` 冒頭の `QUESTIONS` 配列を編集し、同じフォルダをそのまま配信し直す（サーバーはそのまま、ブラウザを再読み込み）だけです。
問題IDを変えなければ、既存の履歴はそのまま引き継がれます。

## スマホのホーム画面に追加（PWA）

このアプリは PWA（`manifest.webmanifest` + `sw.js` + アイコン）に対応しています。公開URL（https）をスマホで開いてから:

- **iPhone / iPad（Safari）**：画面下の「共有」ボタン →「ホーム画面に追加」→「追加」。
  ※ iOS では Safari から追加してください（他ブラウザからは機能が限られます）。
- **Android（Chrome）**：右上「︙」メニュー →「アプリをインストール」または「ホーム画面に追加」。

ホーム画面のアイコンから起動すると、アドレスバーのない全画面（standalone）で開きます。

### 更新はどう届くか

- `sw.js` は `index.html` と `app.js`（問題データ）を **ネットワーク優先** で取得します。
  このフォルダの `app.js` を編集して保存すれば、ホーム画面のアイコンから開き直す（または再読み込み）だけで新しい問題が反映されます。再インストールは不要です。
- CSS・アイコンはキャッシュ優先で、裏で最新を取り直します（次回起動時に反映）。
- オフライン時は最後に取得した版で動きます。
- `sw.js` 自体を大きく変えるときは `CACHE` の版名（`shoshi-ox-shell-v23`）を上げてください。

### 注意

- 学習履歴（localStorage）は **URL（オリジン）ごと** に保存されます。URLが変わると履歴は引き継がれません。同じURLで使い続けてください。
- iOS では「Safari で開いたページ」と「ホーム画面のアプリ」の履歴が別々になることがあります。ホーム画面版で学習を続けるのがおすすめです。
- Cloudflare quick tunnel（`cloudflared tunnel --url http://127.0.0.1:8765`）の `*.trycloudflare.com` URL は、トンネルを再起動すると変わります（※現在のボックス環境では外向きポート7844が遮断されており、quick tunnel は接続できません）。固定URLが必要な場合は名前付きトンネルや静的ホスティングへの配置を検討してください。
